Link Keeper

Short codes for long links, kept in this browser.

i This is not a URL shortener, and it cannot be one. There is no server here, so a code only resolves in the browser that created it — send someone a #/x/abc link and it will not find anything. What it is good for is a personal library: give the links you keep re-pasting a short handle you can actually remember, and search them later.
