Encrypted Vault

Notes and credentials encrypted with AES-GCM behind one master password, using the browser's own crypto.

! Read this before you trust it with anything. This is a demonstration of the browser's crypto primitives, not a password manager. The vault lives in this browser's storage: clearing site data destroys it, and there is no recovery if you forget the master password. It cannot protect you from malware on the machine, and anything held in memory while unlocked is visible to other scripts on this origin. Export a backup, and use a dedicated password manager for anything that matters.
